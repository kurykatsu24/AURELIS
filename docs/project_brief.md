# AURELIS - Project Brief

## 1. Project Overview
AURELIS is a local network monitoring and
performance analysis system designed to help
users observe connected devices, evaluate
network connectivity, and review network
performance.

## 2. Objectives
- Discover devices within an authorized
  local network.
- Monitor device connectivity.
- Measure latency and packet loss.
- Generate network performance reports.
- Provide basic security recommendations.

## 3. Core Technologies
- Python
- Flask
- HTML
- CSS
- JavaScript
